# Verification plan
Layers: (1) unit TBs per module (`tb/tb_<module>.sv`) with independent expected-value code, random valid gaps, extremes, multi-frame and reset; (2) integration: `tb/tb_harris.sv` (module `tb_harris_top`) with a SystemVerilog golden model inside the testbench, 28 directed and random tests checking per-output R_s, corner flag, order and exact 10-cycle latency, plus `sim/crosscheck.py`, which compares the RTL with the Python model (`model/harris_reference.py`) on a 64x64 image; (3) numerical extremes inside the unit TBs (bounds checked: Ix/Iy +-1020, Pxx 1,040,400, Sxx 26,010,000, R_s min -5.539e18).
Regression: `./run_sim.sh` (unit TBs, the self-contained `tb_harris_top`, and `sim/crosscheck.py` against the Python model). Nonzero exit on failure.
Top-level reset mid-frame and wide images (64x64, 256x20, 640x10, plus the 7x7 minimum) are covered by running tb_harris_top with different W, H. Not covered: gate-level sim, formal, functional coverage metrics, widths above 640.
